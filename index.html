trim-1 demo

Not the intended use. trim-1 is built to shrink one piece of an agent's context (a tool result, file or log) down to the lines the current query needs. This page uses it to search a whole codebase instead. The intended use, from the model card:

go install github.com/caveman-ai/trim-1/cmd/trim@latest
trim --query "why does the build fail" build.log

Loading…

All files go in as one text. Each file starts with a header line:

==> colbert/indexing/collection_indexer.py <==
...every line of that file...
==> colbert/searcher.py <==
...every line of that file...

This is a static copy. Queries run in your browser: trim-1 is compiled to WebAssembly (trim.wasm) and scores corpus.txt, the same joined text the server builds. Nothing is saved. To save traces, run the server locally (see the README).

trim-1's raw output: every line of the text, in order, with its score (0 to 1, how likely the line is needed to answer the query). Blank lines always score 0.
